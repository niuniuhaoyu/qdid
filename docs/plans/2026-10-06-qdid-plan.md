# qdid — 分位数/分布型 DiD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个正确、可用、有文档的 Stata 包 `qdid`，估计两期 DiD 下的分位数处理效应 QTT(q)，含统一置信带与可选协变量。

**Architecture:** 扁平 Stata 包结构（.ado/.sthlp 在根目录，支持 `net install`）。核心 `qdid.ado` 按 Callaway & Li (2019) 构造未处理反事实分布的分位数并估计 QTT(q)；聚类自助出逐点 CI；`cband` 用 multiplier bootstrap 出 sup-t 统一带。正确性靠"模拟恢复已知 QTT + 与 R 对拍（若可装 R）"。

**Tech Stack:** Stata 19 MP（`D:\Stata\StataMP-64.exe`）+ Mata；R（对拍，需补装）；Git/GitHub。

**Spec:** `qdid/docs/specs/2026-10-06-qdid-design.md`

## Global Constraints

- Stata 16+
- 包名 `qdid`；扁平布局；许可证 AGPL-3.0；文档英文
- 估计量与识别以 Callaway & Li (2019) 原文为准，**禁止凭印象硬编**
- 默认固定随机种子，保证无 `seed()` 时结果可复现
- 遵守 `SOP/SOP_AI辅助编程核验.md` 与 `SOP/SOP_环境与工具链.md`

## Review Focus

最易踩坑、必须逐一配测试：

1. **未处理反事实分布的分位数构造**——QTT 识别的核心难点，构造错则整条曲线错。（Task 1、3）
2. **处理组/对照组方向**——`treat` 的 0/1 定义反了会让 QTT 符号全反。（Task 3）
3. **无 D=0/对照组缺失**——数据里没有对照组时基线无法定义，应报错而非静默出错。（Task 3）
4. **协变量含缺失/常数列**——应报错或按论文明确处理，不能静默。（Task 5）
5. **统一带影响函数**——`cband` 的 IF 推导/组合错会让带过窄、覆盖不足。（Task 4）
6. **默认种子可复现**——不设 `seed()` 也要能复现。（Task 3）
7. **R 环境缺失**——对拍依赖 R（本机当前未装），须先补装或降级为模拟自洽并标注。（Task 6）
